## Controller

- TacMap: **View**.
- Default layout (Halopedia HINF:Control_schemes, fetched 2026-10-14): A jump, B crouch/slide, X reload/vent/interact, Y switch weapon (hold to drop), Right Bumper use equipment, Left Bumper throw grenade, Right Stick click melee, Left Stick click sprint, D-pad Up helmet light/mark, Down AI scan, Left Switch Grenade, Right Switch Equipment. In the campaign, D-pad Right opens the Equipment Switcher and D-pad Right/Down/Left/Up then equip slots 1-4; D-pad Left opens the Grenade Switcher (Dynamo/Spike/Frag/Plasma on Right/Down/Left/Up). The D-pad bindings are identical in every preset layout; only Use Equipment, Throw Grenade and Melee move (Legacy, Bumper Jumper, Recon, Button Puncher, Helljumper). Any edit makes the layout "Custom" (Halo Waypoint support page, search summary). Whether Switch Equipment can be rebound off the D-pad in Custom is not confirmed. [spoiler: none · enemy-tier: 0 · puzzle-tier: 0 · confidence: medium · _source: web research halopedia.org 2026-10-14]
- Rear-paddle controllers (for example the 8BitDo Pro 2): the two rear paddles P1/P2 are set in 8BitDo Ultimate Software (any input or macro per GamesBeat/PCWorld and 8BitDo support, search summaries only); X-input mode shows LED 2 blinking; three profiles via the Profile button. Paddle-to-D-pad remap for the equipment switcher is an untested suggestion. [confidence: low · _source: web research 2026-10-14]
- Common recommended settings: lower center deadzones (move stick ~0, look stick ~0-1.5 axial) for faster response; vibration off (reduces aim disruption); hold-to-crouch on; auto-clamber off.
