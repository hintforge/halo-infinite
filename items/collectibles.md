## Audio logs

Three sub-types: UNSC, Banished, Spartan -- **104 in total: 37 UNSC / 28 Banished / 39 Spartan** (P3: TheGamer, Gamerpillar and a "104 logs" video guide, title only; MapGenie's map carries exactly 37 / 28 / 39 markers, 2026-10-06). Some are mission-bound; all are recoverable via Mission Replay. ## Item codes and map grid

Every collectible marker on the map site except the 15 High Value Targets has a **code**: a type letter plus a number, counted in map reading order (north to south, then west to east) over the whole map, so a code names the same item on every map page and in every region file (271 coded markers). Each marker also has a **grid cell**: columns A-H run west to east and rows 1-9 north to south, in 0.1-unit cells of the map site's coordinates (the in-game TacMap prints no grid; the definition is in `../optional_zones/spartan_cores_plot.md`). A marker outside the A-H columns reads "west of A3" or "east of H4". Both appear as the Code and Cell columns of every row in `../optional_zones/<zone>_collectibles.md`; Skull codes are also in `skulls.md` and core codes in `../optional_zones/spartan_cores_plot.md`. FOB, outpost and Forerunner-site cells: `../optional_zones/index.md` "Landmarks by grid cell". What the spot looks like on arrival (from the map site's player screenshots, 185 items): "Approach notes" at the end of each region file, and the mission-bound ones at the end of this section.
